# Engram: a study planner you shape into your own

Engram is a calendar-based study planner for Mac, with a built-in Claude assistant. It was built by
a UCL student for himself. This copy is a **starting point**: Claude will ask you what you need,
then change the app until it fits you, and you never have to touch any code.

You do not need to know anything technical. Claude does all of that part.

## What you need

- A **Mac with an Apple chip** (any MacBook from late 2020 onwards).
- The **Claude app** from claude.ai/download, signed in to a paid Claude plan (Pro or Max).
  It has a **Code** tab: that's what you'll use.
- About **30 minutes** the first time. You can stop and carry on later: Claude saves its progress.

## How to start (3 steps)

**1. Open the Code tab** in the Claude app and choose any folder to work in (your Documents folder
is fine). Then, in the little menu next to the message box that says how Claude asks for
permission, choose **Bypass permissions**. (This means Claude won't stop to ask before every
small step. It only works inside this project and the app's own data, and every change it makes is
saved so it can be undone. If you can't find the menu, don't worry: carry on, and click Allow if Claude asks.)

**2. Copy this message, paste it in, and send it:**

> Hi Claude. A friend gave me an app to use as a starting point for my own study planner:
> https://github.com/misha-park/engram-starter
> I'm not technical, so please do all the technical steps yourself and explain things simply.
> Please download it into a new folder called "Engram" inside my current folder, open that folder,
> read the files CLAUDE.md and ONBOARDING.md in it, and then follow them to set everything up and
> ask me what I need.

**3. Answer Claude's questions.** It will install what it needs, show you the app on pretend data,
and ask what you want to keep, change or add. Say what you want in your own words. If a Mac popup
appears, Claude will tell you what to click.

## Afterwards

Whenever you want a change: open the **Engram** folder in the Code tab and tell Claude what you want
("add a countdown to my finals", "I don't need the dissertation page", "this button is confusing").
Claude will make the change, test it, and the app will show **Restart to update**. If you don't like
a change, say "undo that".

## Good to know

- **Your data stays on your Mac.** Timetable, files and notes are stored locally and backed up
  daily to iCloud Drive. Nothing is sent anywhere except what you choose to ask Claude.
- **Passwords:** Claude will never ask you to type a password into the chat. You sign in to UCL
  Moodle on UCL's own page.
- **This uses your Claude plan.** A long first session uses a fair amount of your allowance.
- **If you get stuck:** tell Claude what you see (a screenshot helps). It will fix it.
